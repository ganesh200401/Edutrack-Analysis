# EduTrack – Student Analytics Power BI Report

## 📊 Project Overview

EduTrack is an interactive Power BI report developed to analyze student performance, attendance, fee collection, dropout and retention patterns.

The project demonstrates an end-to-end Data Analyst workflow using MySQL, Power BI and DAX.

## 🎯 Objectives

- Analyze overall student demographics
- Evaluate academic performance
- Monitor student attendance and engagement
- Analyze fee collection and outstanding fees
- Understand dropout patterns
- Analyze student retention

## 🛠️ Tools & Technologies

- MySQL
- Power BI
- DAX
- Microsoft Excel
- SQL
- Data Cleaning
- Data Modeling
- Data Visualization

## 🗂️ Dataset

The dataset is synthetically generated for educational and portfolio purposes.

It contains seven relational tables:

- Students
- Courses
- Teachers
- Performance
- Attendance
- Fees
- Dropouts

The dataset does not contain real student information.

## 🧹 Data Cleaning

Data quality issues were identified and handled using MySQL, including:

- Missing values
- Duplicate records
- Inconsistent categorical values
- Extra spaces
- Invalid values
- Duplicate transaction records
- Data validation

## 📈 Power BI Report

The report contains five pages:

### 1. EduTrack Overview
Provides an overall view of students, courses, teachers, demographics and admission information.

### 2. Academic Performance
Analyzes marks, pass rate, subjects, courses, exam types and academic performance.

### 3. Attendance & Engagement
Analyzes attendance percentage, classes held, classes attended and attendance status.

### 4. Fee & Payment Analysis
Analyzes total fees, paid fees, outstanding fees, payment methods and payment trends.

### 5. Dropout & Retention Analysis
Analyzes dropout reasons, exit types, dropout rate and student retention.

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. If required, update the data source connection.
4. Refresh the data.
5. Explore the five report pages using the navigation buttons and slicers.
